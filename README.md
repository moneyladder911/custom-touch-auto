# Custom Touch Auto Repair - Premium Website

Designed as a high-conversion, luxury automotive workshop landing page.

## Tech Stack
- **Vite** (Vanilla JS Template)
- **HTML5 & CSS3** (Custom properties, Flexbox/Grid)
- **Vanilla JavaScript** (Scroll animations, mobile menu)

## Setup & Run

1.  Install dependencies:
    ```bash
    npm install
    ```

2.  Start the development server:
    ```bash
    npm run dev
    ```

3.  Open your browser at `http://localhost:5173`.

## Features
- **Premium Aesthetics**: Dark mode, glassmorphism, smooth gradients.
- **Responsive Design**: Mobile-first approach.
- **High-Quality Assets**: Custom generated 8k photorealistic images for Hero, Services, and Gallery.
- **Performance**: Lightweight vanilla JS, avoiding heavy framework overhead.

## Project Structure
- `index.html`: Main landing page structure.
- `style.css`: All styling logic (variables, animations, media queries).
- `main.js`: Interactive elements (menu, scroll observer).
- `public/images/`: Contains all generated assets.
